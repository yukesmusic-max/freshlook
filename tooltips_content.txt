# FRESHLOOK TOOL TIPS -- wired in via "Enable Tool Tips" (View).
#
# One entry per row in Settings > View and Settings > Functions, in the
# order they currently appear. Each entry is either a tool tip (the same
# "## slide" format as tutorial_content.txt) or NO TOOL TIP for a row that
# doesn't get one. Entries are separated by a line of "=" characters.
#
# A tool tip fires right after you flip a toggle (E2) or select an action
# (K3) in Settings -- its own final slide's K2/K3 is what actually commits
# the change (see k2:/k3: below); declining just leaves the row as it was.
#
# Besides tutorial_content.txt's own k2:/k3: actions (next, skip_next,
# back, end, disable_quicknav, alphabetize, autosort, replace_home), these
# two are tool-tip-only:
#   enable / disable   -- sets *this row's own* option to yes/no
#   backup             -- runs Backup Organization, shows the real filename
# `end` on a tool tip means "leave this row as it was" (same as K1 long).
#
# DEFAULT lines record what the row ships at today, matching the actual
# param default in the code -- these are what this document is meant to
# let you configure later. If a user has already changed a toggle away
# from its default, that choice always wins; DEFAULT only governs what a
# fresh install (or a reset one) starts at.
#
# "Enable Tool Tips" (View) is the master switch for this whole system --
# listed first below since it's the first row after View's separator.

================================================================================

> TOOL TIP: View > Enable Tool Tips
NO TOOL TIP -- this is the on/off switch for the tool tip system itself;
showing a tool tip to explain the tool tips would be a little silly, and
anyone turning it off already knows what it does.
DEFAULT : YES

================================================================================

> TOOL TIP: View > View Mode
NO TOOL TIP -- this is a 3-way cycle (Compact / Expanded / Linear), not an
enable/disable toggle, so the K2-disable/K3-enable tool tip shape doesn't
apply. If View Mode ever gets its own explainer, it'll need a different
format than the rest of these.
DEFAULT : Compact

================================================================================
